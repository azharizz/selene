# PRODUCT.md implementation coverage

Scope: the Vega MVP in [PRODUCT.md](../../PRODUCT.md), plus the latest request for a cross-app assistant. The companion is the launch surface; the authored story and Offside Practice packages remain explicit secondary options. Third-party requests use genuine provider snapshots, separate companion sessions and a viewer-detail fallback. An optional scene-context adapter requires an authorized endpoint; overlays inside viewing apps remain unsupported without a platform contract. See [the September 19 code-review results](companion-review.md) for executed checks and remaining gates.

## Implemented flow

1. Select a supported playback session, or open an own-player film: Football Match (`football-match`) or The Missing Crown (`the-missing-crown`). Both request surfaces support explicit Family/Solo selection. SELENE owns captions and transport only for its catalog films; a third-party provider retains authority over its own playback.
2. A playback tile opens one question directly. That sampled moment stays fixed. Type a question with any scene detail, or select a quick question; need, recipient and language live in optional preferences. Use D-pad, keyboard, or capability-gated voice. Playback lists contain three sessions per page.
3. Send the request, keep watching, or pause to explore. Imported questions supply all completed captions, their time-filtered movie graph and ten freshly decoded JPEGs directly to answer generation. Missing detail permits one clarification tied to the same moment.
4. Validate schema, original evidence IDs, captured time and SVG safety. Ordinary generated explanations then render through the same isolated SVG/WAAPI page as the viewer: the configured model receives the reduced-motion diagram, three actual animation-stage screenshots and measured target positions, and may keep or revise the response for at most two feedback turns. Validate and render every revision before display; retain a limit marker if the final revision has no further feedback verdict, without a subjective wording veto or word-count gate. Existing structural repair remains separate. Prepared examples and clarifications bypass visual feedback; Guided Return and followed-thread updates retain their separate evidence review and existing text/quiet contracts. Source citations and model feedback do not prove factual or teaching accuracy.
5. Display one answer and matching visual, silently. Compact output accompanies continued playback; paused output has more room. The host reads actual playback events and rejects stale responses. A newer transport action takes precedence over a delayed pause request.
6. A Life Connection needs an explicit personal-connection request or the viewer's selection and pause confirmation. Show one question for the selected recipient. The family supplies its own perspective; no microphone or recording starts. Back closes without resuming. Resume is a separate viewer action.
7. Close the moment or leave the app. Cancel pending work and speech, restore film audio, discard the transient question, and release background playback. Return requires a manual Continue action.

## Deliberate limits

- **No ordinary semantic veto.** The answer model uses supplied evidence and general knowledge for concepts, keeping general rules separate from observed film events. Source/time/SVG validation remains; recap/thread updates retain review. Caption graph interpretations and pixel claims remain provisional, not guaranteed truth.
- **Memory is scoped.** Each viewing/private conversation retains its latest successful request, answer, diagram and visual feedback. Same-title, non-future help can support follow-up continuity, never source evidence; explicit private conversation context takes precedence. An explicit new topic starts fresh private memory, and session closure discards it. Movie graphs belong only to their imported title; existing imports generate them once in relay memory. No durable learning, persistent general graph or answer-derived connection learning remains. Explicit generate requests and imported questions bypass response reuse; legacy session reuse is bounded to 16 responses and includes continuity in its key. The relay retains at most eight sessions and does not save family answers.
- **Context is explicit.** All completed captions through the question are retained, without a runtime cue-count cutoff. Requested images are t±2/4/6/8/10, selected at or before each requested source timestamp. The next ten seconds of pictures are authorized lookahead; future captions and graph labels remain excluded. Clip-edge/duplicate frames are marked missing. Provider context/output limits can still fail rather than silently truncate.
- **Voice needs device evidence.** Browser and native microphone paths require explicit recording permission/consent and transcript review; app microphone input is not the remote's Alexa microphone. The native Vega PlayerSession receives own-player playback commands and audio-focus state. The companion offers browser voice only while provider playback is explicitly paused. The local simulated Alexa+-style MCP router is not an Amazon Alexa integration.
- **Prime Video remains gated.** Saved VVD evidence contains no Prime Video provider. The public client provides no timed dialogue or third-party overlay. The optional licensed scene-context adapter can supply automatic grounding only when a real authorized endpoint is configured; otherwise the fallback explains an explicit viewer account. See [companion evidence](companion.md) and [scene-context contract](scene-context.md).
- **No unsolicited intervention.** Host recommendations are disabled. The no-request path is quiet; background scene tracking causes no model calls.
- **Private mirror.** An explicit session pairing can stream a Moment Response to a reachable phone/tablet over SSE; the private device may read it aloud after a tap. Direct TV headset routing depends on platform APIs. Fire OS has its own player but no equivalent third-party playback discovery. Official local AVG preview and the simulated MCP router do not establish an Amazon Alexa adapter; third-party sports playback still needs verified provider context or viewer detail.
